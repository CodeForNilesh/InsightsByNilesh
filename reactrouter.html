React Router Explained

React Router helps build single-page applications with clean URLs and nested navigation.

React Router is the standard library for handling navigation in React apps. It lets you map URL paths to UI components and manage browser history smoothly.

📚 Topics at a Glance

Core Components Related Hooks Full Example Key Considerations

🔑 Core Components

1. BrowserRouter

Wraps your app to enable routing and uses the HTML5 history API for clean URLs.

import { BrowserRouter } from "react-router-dom";

function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Home />} />
      </Routes>
    </BrowserRouter>
  );
}

2. Routes

Acts as a container for all route definitions and ensures only one matching route is rendered.

<Routes>
  <Route path="/" element={<Home />} />
  <Route path="/about" element={<About />} />
</Routes>

3. Route

Maps a URL path to a component and can support nested routes with <Outlet />.

<Route path="/dashboard" element={<Dashboard />}>
  <Route index element={<DashboardHome />} />
  <Route path="settings" element={<Settings />} />
</Route>

🧩 Related Hooks

Hook Purpose Example
useNavigate Programmatic navigation navigate("/login")
useParams Access dynamic route parameters const { id } = useParams();
useLocation Get current URL information const location = useLocation();
useMatch Match the current URL against a pattern const match = useMatch("/products/:id");

⚡ Example Putting It All Together

import { BrowserRouter, Routes, Route, useNavigate, useParams, useLocation } from "react-router-dom";

function Product() {
  const { productId } = useParams();
  const location = useLocation();
  return (
    <div>
      <h2>Product ID: {productId}</h2>
      <p>Current Path: {location.pathname}</p>
    </div>
  );
}

function Home() {
  const navigate = useNavigate();
  return <button onClick={() => navigate("/products/42")}>Go to Product</button>;
}

export default function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/products/:productId" element={<Product />} />
      </Routes>
    </BrowserRouter>
  );
}

🚨 Key Considerations

  • Always wrap your app in <BrowserRouter>.
  • Use <Outlet /> for nested routes.
  • Prefer hooks over older patterns like withRouter.
  • Index routes act as defaults for nested paths.
